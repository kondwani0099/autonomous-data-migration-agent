# Code Quality Skill Directive

<QUALITY_STANDARDS>
1. **Python Linter & Formatter (`Ruff`)**: Enforce clean PEP 8 styling, unused import removal, and formatting.
2. **Python Static Type Checking (`mypy`)**: Enforce explicit type annotations on function parameters and return types.
3. **Frontend Linting & Formatting (`ESLint` + `Prettier`)**: Enforce Vue 3 recommended linting rules and TypeScript strict mode.
4. **SOLID & Clean Code**: Keep functions short and single-purpose. Maintain cyclomatic complexity within reasonable limits.
</QUALITY_STANDARDS>
